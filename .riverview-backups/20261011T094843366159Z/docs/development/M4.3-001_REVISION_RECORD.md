## Design and controls

`LocalInferenceAction` is an optional in-process action adapter for an OpenAI-compatible local HTTP endpoint. It accepts only literal loopback HTTP `/v1`, bounds input (4 KiB default), output (8 KiB default), generated tokens (128 default), and timeout (90 seconds default), and rejects non-complete responses. Prompts are not stored; the worker ledger stores their SHA-256 input digest. A JSON output artifact is durably stored with its own canonical digest, then separately verified by another registered identity. `local.inference.v1` maps to the existing exact `assignment.execute` grant and is checked at claim/action/result boundaries. Existing deterministic SHA-256 behavior remains the default.

The CPU experiment uses llama.cpp from upstream tag `v0.6.0`, commit `d81235049384534c167caea52b85a694f6103d14`, and the Qwen3-0.6B-GGUF model at immutable revision `23749fefcc72300e3a2ad315e1317431b06b590a`. The model file SHA-256 is `9465e63a22add5354d9bb4b99e90117043c7124007664907259bd16d043bb031`; weights remain outside Git. License is Apache-2.0 per the model card. Build/runtime/model files are temporary development artifacts, not deployment packages.
