## RV-M1.1-002 — Windows archive deployment failure and repair

[PR failure comment](https://github.com/ppow1/Riverview-/pull/2#issuecomment-6091930352)
records the 2026-10-10T01:00:02Z attempt at commit
`11e09d88a6ee39d943d6222dd5f12c773b8a120b`, archive SHA-256
`6af503497c1e4af052a26ddaafb39bdc6dcb78f40b9511b3c183487d08f4851e`.
SSH, sudo, transfer, commit and manifest verification passed. Installation failed
at line 15 (`set: Illegal option -`, exit 2); acceptance was skipped. This failure
is retained and does not constitute M1.1 PASS or evidence of DB changes.

The original Windows archive is not accessible to this cloud environment; its
bytes have NOT been inspected here. User confirmed its Windows and Camrui paths.
The preserved predecessor builder was executed against the same shell-file bytes
with Git `core.autocrlf=true`. The built tarball contains `set -eu\r\n` in both
scripts; executing only that line in Linux /bin/sh reproduces the exact error.
Committed blobs at the failed SHA are LF-only. Root cause demonstrated for the
packaging path: `git archive` applies working-tree line-ending conversion, and
the old builder hashes converted bytes, so manifest PASS does not detect this.
No transfer/extraction corruption is asserted without the original artifact.

Repair: raw committed Git blob packaging, explicit LF checkout attributes for
shell/systemd files, fail-before-output shell-byte validation, independent archive
verifier and regression tests for Windows settings, explicit CRLF attributes,
manifest bytes, BOM/NUL/CRLF rejection and Linux shell parse/guarded execution of
both scripts. Shell source itself is unchanged; original source SHA-256 values
are retained in the repair evidence. No privileged host operation ran in tests.

Repair validation: 36 discovered, 33 passed, 3 existing PostgreSQL skips, 0 failures.
See [repair evidence](../../evidence/checkouts/RUNTIME-BASELINE/packaging-repair.md).
Exact predecessor bytes/hashes and restoration instructions are in
[M1.1 repair revision record](M1.1_PACKAGING_REVISION_RECORD.md).
