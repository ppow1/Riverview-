# Riverview capability inventory

Inventory date: 2026-10-25. This describes source and evidence across The Estate, canonical Riverview, the deployed `Riverview-` website/backend, the historical archive, and infrastructure runbooks. Historical and experimental implementations are not presumed to be running.

## Current deployed website baseline

The verified production baseline for this Batch 1 increment is V2 release `RV-WEB-V2-ACCEPTANCE-936d6ccf0a0d`, source `936d6ccf0a0da92a44a22fdca3a75eaabd463708`. V1 and V2 share authenticated `/api/v1` services. The resident profile/catalog operation is Steward and institutional-authority protected; an anonymous 401 establishes a boundary, not an operation-specific authorization grant.

Status vocabulary:

- **Live (verified):** observed on the production V1/V2 endpoint on 2026-10-24 or prior recorded live acceptance.
- **Implemented:** source implementation and tests/evidence exist; deployment is not verified in this inventory.
- **Historically tested:** explicit dated test evidence exists; current runtime is unverified.
- **Proposed/metadata:** design, registry, or uninstalled prototype only.
- **Missing:** no equivalent function found in the surveyed V2 UI/source.

## Cross-repository findings

- `ppow1/theestate` is a rich operational model/prototype with file-based runtime artifacts and a local-first command center. The command center module explicitly says it avoids authentication and cloud services; it is not safe to expose as a production control plane.
- `ppow1/Riverview` main contains the event-driven/PostgreSQL design, model/GPU documentation, Stream Deck plugin, and historically tested spatial prototype. Its tests and checkpoint records do not prove a service is currently deployed.
- `ppow1/Riverview-` contains the deployed V1/V2 website and authenticated backend. V2 is the current presentation baseline, not a wholesale replacement for the other repositories' durable source data.
- `ppow1/Riverview-Historical-Archive` declares itself historical and non-authoritative. Its checked-out archive contains no images or site binaries.
- `ppow1/Riverview-SSH-Runbooks` preserves physical/display/network/Quest findings. Hardware-verified facts there are not assumed to be active UI services.

## Decision

Build on the deployed Riverview backend/API and event/audit identifiers. Treat Estate runtime JSON, historical prototypes, static concept art, and archived evidence as references or source-specific artifacts until an explicit adapter establishes current authority and live health.
