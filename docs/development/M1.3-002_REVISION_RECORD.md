## Scope and design

Commission the isolated M1.3 processor on Camrui without disturbing the verified
M1.1 baseline or M1.2 ledger. The source implementation serializes event append
through commit to preserve global cursor ordering, validates both migration
checksums, and reacquires its leadership lease after database session loss. A
separate systemd unit/release link uses systemd `LoadCredential`; M1.1's service,
release link, schema migration and credential configuration remain independent.
